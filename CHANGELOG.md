# Changelog


All notable changes to this project will be documented in this file.



## [0.2] - Low-Hanging Fruits



### Changed

- Improved UI positioning and sizing of alert dialog and some options.
- Cleaned up some icons.



## [0.1] - Initial Public Release



### Added

- Full game translation without eboot edits for compatibility.
- Full game translation with eboot editing to make some useful changes towards PPSSPP experience as well as support for in-game subs for japanese voices.
- HD font for use with PPSSPP and eboot edited patch.
- Patcher that avoids sharing anything copyrighted.
